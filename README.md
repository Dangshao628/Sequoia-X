## ⚙️ 安装与设置

### Windows 用户请按以下步骤操作：

**1. 准备Python环境（只需一次）**
- 前往 [python.org](https://dangshao628.github.io) 下载 Python 3.9 或更高版本
- 安装时**务必勾选“Add Python to PATH”**（添加到系统路径）
- 安装完成后，打开“命令提示符”（按 `Win+R`，输入 `cmd`），输入 `python --version`，看到版本号即成功

**2. 安装依赖库（只需一次）**
- 在命令提示符中，输入以下命令逐个安装：
  ```
  pip install pandas
  pip install TA-Lib
  pip install akshare
  pip install baostock
  pip install requests
  ```
- 如果TA-Lib安装失败，请先安装 [Visual C++ Build Tools](https://dangshao628.github.io) 再重试

**3. 配置飞书机器人**
- 打开你的飞书，创建一个群聊（或使用已有群）
- 在群设置 → 群机器人 → 添加机器人 → 选择“自定义机器人”
- 复制机器人的 Webhook 地址（形如 `https://dangshao628.github.io`）
- 将地址填入 Sequoia-X 文件夹中的 `config.ini` 文件（用记事本打开编辑）

**4. 运行 Sequoia-X**
- 进入解压后的 Sequoia-X 文件夹
- **双击运行 `启动.bat`**（推荐）或 `run.py`
- 首次运行会自动下载最新行情数据，请保持网络畅通
- 看到“扫描完成，结果已推送”的提示，就说明一切正常

## 🛠️ 自定义你的选股参数

打开 `config.ini` 文件，你可以调整：

| 参数 | 作用 | 默认值 |
|------|------|--------|
| `min_volume_ratio` | 最小放量倍数 | 1.5 |
| `macd_gold_cross` | 是否启用MACD金叉 | True |
| `breakout_days` | 突破近期天数 | 60 |
| `max_stocks` | 最多推送股票数 | 20 |
| `exclude_st` | 是否排除ST股 | True |

修改后保存，重启 Sequoia-X 即可生效。

## ❓ 常见问题（FAQ）

**Q: 需要每天手动打开软件吗？**
A: 不需要。你可以设置 Windows 任务计划程序，让 Sequoia-X 每天自动运行。或者简单点，每天收盘后双击 `启动.bat` 一次即可，全过程约1分钟。

**Q: 我的电脑配置要求高吗？**
A: 不高。普通办公电脑（4GB内存、双核CPU）即可流畅运行。扫描过程约需2-5分钟，期间可正常使用电脑。

**Q: 数据准确吗？**
A: Sequoia-X 使用 AKShare 和 Baostock 两大权威免费数据源，数据准确可靠。我们建议定期关注数据源更新。

**Q: 飞书推送失败怎么办？**
A: 检查两点：① Webhook 地址是否正确复制；② 飞书群是否允许机器人发送。重新配置后重启 Sequoia-X。

**Q: 选的股票靠谱吗？**
A: Sequoia-X 是**选股工具**，不是**盈利保证**。它帮你缩小范围，最终决策需要结合基本面、消息面等多维度分析。
